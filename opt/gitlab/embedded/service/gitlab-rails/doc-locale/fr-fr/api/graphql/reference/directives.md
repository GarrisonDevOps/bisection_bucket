Une directive fournit un moyen de décrire un comportement alternatif d'exécution au moment de l'exécution et de validation des types dans un document GraphQL. Pour plus d'informations, consultez la [documentation sur les directives GraphQL](https://graphql.org/learn/queries/#directives).

> [!warning]
> Les éléments dépréciés sont prévus pour être supprimés dans une future release. Pour plus d'informations, consultez le [processus de dépréciation](../_index.md#deprecation-and-removal-process) de GitLab.

## `granularScope` {#granularscope}

Déclare les autorisations granulaires de jeton d'accès personnel requises pour accéder à un champ ou un type, ainsi que la limite d'autorisation (projet, groupe, utilisateur ou instance) à laquelle ces autorisations s'appliquent. Un champ ou un type peut également se soustraire à l'autorisation granulaire de jeton en indiquant une raison de saut.

### Emplacements de `granularScope` {.no_toc} {#granularscope-locations-no_toc}

- `FIELD_DEFINITION`
- `OBJECT`

Il s'agit d'une directive répétable et peut être utilisée avec différents arguments au même emplacement.

### Arguments de `granularScope` {.no_toc} {#granularscope-arguments-no_toc}

| Nom | Type | Description |
| ---- | ---- | ----------- |
| `assignableWhen` | [`[String!]`](scalars.md#string) | Conditions que l'utilisateur actuel doit remplir pour que les permissions soient proposées dans l'interface de création de jeton. Il ne s'agit pas d'un contrôle de sécurité : le type, la mutation ou le champ doit toujours appliquer les conditions. Valeurs valides : admin, gitlab_team_member, saas, self_managed. |
| `boundary` | [`String`](scalars.md#string) | Nom de la méthode à appeler sur l'objet résolu pour extraire la limite d'autorisation (Projet/Groupe). À utiliser lorsque l'objet est déjà résolu (champs sur les types, champs imbriqués). |
| `boundaryArgument` | [`String`](scalars.md#string) | Nom de l'argument contenant la limite d'autorisation (chemin ou GlobalID). À utiliser pour les mutations et les champs de requête où la limite est transmise en tant qu'argument. |
| `boundaryType` | [`PermissionBoundary`](enums.md#permissionboundary) | Le type de limite d'autorisation (project, group, user, instance). Utilisé pour la validation et la documentation de la limite de permission. |
| `permissions` | [`[String!]`](scalars.md#string) | Permissions de portée granulaire requises pour accéder au champ ou au type. |
| `skipReason` | [`String`](scalars.md#string) | Raison pour laquelle le champ ou le type exclut intentionnellement l'autorisation granulaire par jeton. |
