Mattermost inclus est supprimé du paquet Linux dans GitLab 19.0. Si vous utilisez actuellement Mattermost inclus, consultez [Migration du paquet Linux vers Mattermost Standalone](https://docs.mattermost.com/administration-guide/onboard/migrate-gitlab-omnibus.html) pour obtenir des instructions de migration. Les clients n'utilisant pas Mattermost inclus ne sont pas impactés.
