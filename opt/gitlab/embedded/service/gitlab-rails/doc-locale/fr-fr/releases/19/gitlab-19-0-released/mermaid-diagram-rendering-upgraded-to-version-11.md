GitLab utilise désormais [Mermaid version 11](../../../user/markdown.md#mermaid) pour le rendu des diagrammes en Markdown.

Auparavant, GitLab prenait en charge Mermaid version 10. Avec cette mise à niveau, vous avez accès à tous les nouveaux types de diagrammes, améliorations de syntaxe et corrections de bogues introduits dans Mermaid 11, notamment un rendu amélioré pour les organigrammes, les diagrammes de séquence et plus encore.
