Si vous utilisez GitLab Self-Managed avec des modèles auto-hébergés, vous pouvez désormais utiliser Amazon Bedrock Mantle comme fournisseur pris en charge. Mantle est un moteur d'inférence compatible OpenAI pour Amazon Bedrock, ce qui vous permet d'utiliser les SDK et intégrations OpenAI courants avec les modèles Bedrock. Cette fonctionnalité est en version bêta.
