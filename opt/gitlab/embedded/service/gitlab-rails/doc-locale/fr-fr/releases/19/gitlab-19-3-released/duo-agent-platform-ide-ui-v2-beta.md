L'interface GitLab Duo Agentic Chat dans l'extension GitLab pour VS Code et le plugin GitLab Duo pour les IDE JetBrains dispose d'une interface utilisateur repensée, désormais disponible en version bêta. La nouvelle interface est une version reconstruite du panneau Agentic Chat existant, avec les mêmes fonctionnalités sous-jacentes : modèles d'IA, agents, commandes slash et approbations d'outils.

L'interface utilisateur repensée est disponible dans GitLab 19.3 avec :

- GitLab pour VS Code 6.88.1 et versions ultérieures
- Plugin GitLab Duo pour les IDE JetBrains 3.45.2 et versions ultérieures

Pour utiliser la nouvelle interface, [activez les fonctionnalités en version bêta et expérimentales](../../../user/gitlab_duo/turn_on_off.md#turn-on-beta-and-experimental-features) pour votre groupe principal ou votre instance, puis rechargez l'extension. Vous pouvez basculer entre la nouvelle interface et l'interface classique à tout moment depuis le panneau.
