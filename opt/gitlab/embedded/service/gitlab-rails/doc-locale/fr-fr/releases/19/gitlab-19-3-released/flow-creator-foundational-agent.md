Vous pouvez désormais utiliser le Flow Creator, un agent par défaut dédié dans le catalogue d'IA, pour créer des flows personnalisés pour la plateforme GitLab Duo Agent Platform via une conversation en langage naturel. Avec le Flow Creator, vous décrivez ce que vous souhaitez que le flow effectue, et l'agent produit un flow YAML complet et exécutable que vous pouvez enregistrer et utiliser immédiatement. L'agent peut également vous aider à déboguer des flows existants et à expliquer les concepts du framework.
