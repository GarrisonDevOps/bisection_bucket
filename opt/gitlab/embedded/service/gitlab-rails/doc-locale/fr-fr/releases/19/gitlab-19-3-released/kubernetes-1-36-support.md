GitLab prend désormais entièrement en charge Kubernetes version 1.36. Pour déployer vos applications sur Kubernetes et accéder à toutes les fonctionnalités, mettez à niveau vos clusters connectés vers la version la plus récente. Pour plus d'informations, consultez [les versions de Kubernetes prises en charge pour les fonctionnalités GitLab](../../../user/clusters/agent/_index.md#supported-kubernetes-versions-for-gitlab-features).
