Dans les versions précédentes de GitLab, les clients MCP ne pouvaient accéder qu'à un ensemble limité d'outils GitLab. Le serveur MCP de GitLab est désormais en disponibilité générale.

Grâce au serveur MCP, tout agent compatible MCP, tel que Claude Code ou Cursor, bénéficie d'un accès direct au catalogue étendu d'outils GitLab ainsi qu'aux agents et flows de GitLab Duo Agent Platform. Vos agents peuvent intervenir sur davantage de votre workflow GitLab et exécuter des agents et des flows de l'Agent Platform sans quitter votre outil préféré.
