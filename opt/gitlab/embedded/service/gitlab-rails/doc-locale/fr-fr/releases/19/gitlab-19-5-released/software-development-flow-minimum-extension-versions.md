Le flow Software Development s'exécute désormais sur le registre de flows de la plateforme GitLab Duo Agent Platform, la même base que les autres flows. Le flow fonctionne de la même manière dans votre IDE, et les nouveaux correctifs et améliorations sont apportés à cette version.

Pour continuer à utiliser le flow Software Development, mettez à jour votre extension d'éditeur vers l'une de ces versions ou une version ultérieure :

- GitLab pour VS Code 6.85.0
- Plugin GitLab Duo pour les IDE JetBrains 3.40.0
- GitLab pour Visual Studio 0.79.0
