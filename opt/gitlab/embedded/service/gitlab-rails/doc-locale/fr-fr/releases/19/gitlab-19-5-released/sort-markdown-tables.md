Dans les versions précédentes de GitLab, pour trouver des informations dans un grand tableau Markdown, vous deviez parcourir chaque ligne ou copier le tableau dans un tableur.

Vous pouvez désormais trier les tableaux Markdown affichés par n'importe quelle colonne, aussi bien en mode affichage qu'en mode aperçu. Dans un en-tête de colonne, sélectionnez le bouton de tri pour trier les lignes par ordre croissant ou décroissant, puis réinitialisez pour restaurer l'ordre d'origine. Vous pouvez également effectuer le tri à l'aide du clavier.
