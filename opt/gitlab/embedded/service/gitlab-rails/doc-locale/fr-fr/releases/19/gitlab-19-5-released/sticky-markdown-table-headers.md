Dans les versions précédentes de GitLab, lorsque vous faisiez défiler un long tableau, la ligne d'en-tête disparaissait de la vue, ce qui rendait difficile l'identification du contenu de chaque colonne.

Désormais, les en-têtes de tableau restent visibles en haut du tableau lors du défilement, en mode vue, en prévisualisation et dans l'éditeur de texte enrichi. Les en-têtes fixes sont toujours activés, vous n'avez donc pas besoin de modifier les paramètres.
