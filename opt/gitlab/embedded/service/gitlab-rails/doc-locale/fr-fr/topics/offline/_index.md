Les ordinateurs dans un environnement hors ligne sont isolés de l'internet public pour des raisons de sécurité. Cette page répertorie toutes les informations disponibles pour exécuter GitLab dans un environnement hors ligne.

## Démarrage rapide {#quick-start}

Si vous prévoyez de déployer une instance GitLab sur un réseau physiquement isolé et hors ligne, consultez le [guide de démarrage rapide](quick_start_guide.md) pour connaître les étapes de configuration.

Suivez ces bonnes pratiques pour utiliser les fonctionnalités de GitLab dans un environnement hors ligne :

- [Utilisation des scanners GitLab Secure dans un environnement hors ligne](../../user/application_security/offline_deployments/_index.md).
- [Déploiement de GitLab Duo Self-Hosted dans un environnement hors ligne](../../administration/gitlab_duo_self_hosted/offline_deployment.md).
