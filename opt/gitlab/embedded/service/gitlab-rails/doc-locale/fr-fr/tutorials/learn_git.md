GitLab est une plateforme basée sur Git. Comprendre Git est donc essentiel pour tirer le meilleur parti de GitLab.

| [Tirer parti du rebase Git](https://about.gitlab.com/blog/take-advantage-of-git-rebase/) | Découvrez comment utiliser la commande `rebase` dans votre workflow. Durée estimée : 15-20 minutes. | |
| [mettre à jour les messages de commit Git](update_commit_messages/_index.md) | Découvrez comment mettre à jour les messages de commit et pousser les modifications vers GitLab. Durée estimée : 5-10 minutes. | |
