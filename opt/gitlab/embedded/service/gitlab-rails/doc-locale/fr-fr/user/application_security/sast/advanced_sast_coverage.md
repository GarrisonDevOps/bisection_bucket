[GitLab Advanced SAST](gitlab_advanced_sast.md) détecte de nombreux types de vulnérabilités de sécurité potentielles dans le code écrit dans les [langages pris en charge](gitlab_advanced_sast.md#supported-languages).

GitLab attribue un identifiant [Common Weakness Enumeration (CWE)](https://cwe.mitre.org) correspondant à chaque vulnérabilité potentielle. Les identifiants CWE constituent une méthode standard de l'industrie pour identifier les failles de sécurité, mais il est important de savoir :

- Les CWE sont organisées en arborescence. Par exemple, [CWE-22 : Path Traversal](https://cwe.mitre.org/data/definitions/22.html) est un parent de [CWE-23 : Relative Path Traversal](https://cwe.mitre.org/data/definitions/23.html). Un scanner qui détecte spécifiquement les failles de traversée de chemin relatif (CWE-23) détecte par définition également une partie de la catégorie plus générale de traversée de chemin (CWE-22).
- Par souci de clarté, ce tableau identifie les identifiants CWE exacts attribués aux règles GitLab Advanced SAST. Il ne répertorie pas les identifiants parents.

Pour en savoir plus sur les règles utilisées dans GitLab Advanced SAST, consultez [Règles SAST](rules.md#gitlab-advanced-sast).

## Couverture CWE pour Swift et Objective-C {#swift-and-objective-c-cwe-coverage}

{{< details >}}

- Statut : version bêta

{{< /details >}}

L'analyse Swift et Objective-C est en version [bêta](../../../policy/development_stages_support.md#beta) et s'exécute en tant que job CI/CD distinct, `gitlab-advanced-sast-ext`. Pour en savoir plus, consultez [la configuration de Swift et d'Objective-C](advanced_sast_swift_objc.md).
