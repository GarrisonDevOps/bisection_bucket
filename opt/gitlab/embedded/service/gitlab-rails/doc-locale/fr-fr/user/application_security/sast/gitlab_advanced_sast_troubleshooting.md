Lorsque vous utilisez GitLab Advanced SAST, vous pouvez rencontrer les problèmes suivants.

## Analyse SAST avancée prenant plus de temps que prévu {#advanced-sast-scan-running-longer-than-expected}

Si vous avez suivi les étapes d'optimisation et que votre analyse SAST avancée prend toujours plus de temps que prévu, contactez le support GitLab pour obtenir de l'aide supplémentaire avec les informations suivantes :

- [Version de l'analyseur GitLab Advanced SAST](#identify-the-gitlab-advanced-sast-analyzer-version)
- Langage de programmation utilisé dans votre dépôt
- [Journaux de débogage](../troubleshooting_application_security.md#turn-on-debug-level-logging)
- [Artefact de débogage des performances](#generate-a-performance-debugging-artifact)

### Identifier la version de l'analyseur GitLab Advanced SAST {#identify-the-gitlab-advanced-sast-analyzer-version}

Pour identifier la version de l'analyseur GitLab Advanced SAST :

1. Dans la barre supérieure, sélectionnez **Rechercher ou accéder à**, puis recherchez votre projet.
1. Dans la barre latérale gauche, sélectionnez **Version** > **Jobs**.
1. Localisez le job `gitlab-advanced-sast`.
1. Dans la sortie du job, recherchez la chaîne `GitLab GitLab Advanced SAST analyzer`.

Vous devriez trouver la version à la fin de la ligne contenant cette chaîne. Par exemple :

```plaintext
[INFO] [GitLab Advanced SAST] [2025-01-24T15:51:03Z] ▶ GitLab GitLab Advanced SAST analyzer v1.1.1
```

Dans cet exemple, la version est `1.1.1`.

### Générer un artefact de débogage des performances {#generate-a-performance-debugging-artifact}

Pour générer l'artefact `trace.ctf` (dans les projets non C/C++), ajoutez ce qui suit à votre `.gitlab-ci.yml`.

Définissez `RUNNER_SCRIPT_TIMEOUT` sur une valeur inférieure d'au moins 10 minutes à celle de `timeout` pour vous assurer que l'artefact dispose du temps nécessaire à son téléversement.

```yaml
include:
  - template: Jobs/SAST.gitlab-ci.yml

variables:
  GITLAB_ADVANCED_SAST_ENABLED: 'true'
  MEMTRACE: 'trace.ctf'
  DISABLE_MULTI_CORE: true # Disable multi core when collecting memtrace

gitlab-advanced-sast:
  artifacts:
    paths:
      - '**/trace.ctf'  # Collects all trace.ctf files generated by this job
    expire_in: 1 week   # Sets retention for artifacts
    when: always        # Ensures artifact export even if the job fails
  variables:
    RUNNER_SCRIPT_TIMEOUT: 50m
  timeout: 1h
```
