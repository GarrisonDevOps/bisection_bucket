Les types d'événements d'audit sont utilisés pour filtrer les événements d'audit streamés :

- [Pour les instances](../../administration/compliance/audit_event_streaming.md#update-event-filters).
- [Pour les groupes principaux](audit_event_streaming.md#update-event-filters)

Chaque événement d'audit est associé à un type d'événement. Les types d'événements d'audit peuvent autoriser :

- La plupart des événements d'audit à être enregistrés dans la base de données. Disponible dans les éditions Premium et Ultimate. Vous pouvez récupérer les événements d'audit associés à ces types en utilisant le tableau de bord des événements d'audit ou l'[API des événements d'audit](../../api/audit_events.md).
- Tous les événements d'audit à streamer vers des destinations externes. Disponible dans l'édition Ultimate. Vous pouvez streamer les événements d'audit associés à ces types vers des destinations externes si une destination est définie.

La portée d'un type d'événement d'audit limite la disponibilité du type d'événement d'audit à :

- Événements d'audit [Projet, groupe ou utilisateur](audit_events.md).
- Événements d'audit d'[instance](../../administration/compliance/audit_event_reports.md).
