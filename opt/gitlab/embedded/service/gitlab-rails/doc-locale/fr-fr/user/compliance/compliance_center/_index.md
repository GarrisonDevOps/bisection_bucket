Prérequis :

- Vous devez être administrateur ou avoir le rôle Responsable sécurité ou Propriétaire pour le groupe ou le projet.

Le centre de conformité est l'emplacement central permettant aux équipes de conformité de gérer les rapports d'adhésion aux normes de conformité, les rapports de violations et les frameworks de conformité pour leur groupe.

Le centre de conformité comprend :

- [Tableau de bord de vue d'ensemble de la conformité](compliance_overview_dashboard.md).
- [Rapport de statut de conformité](compliance_status_report.md).
- [Rapport de violations de conformité](compliance_violations_report.md).
- [Rapport sur les frameworks de conformité](compliance_frameworks_report.md).
- [Rapport sur les projets de conformité](compliance_projects_report.md).

Pour en savoir plus sur les autres fonctionnalités de conformité GitLab pour les projets, les groupes et les instances, consultez [Fonctionnalités de conformité](../../../administration/compliance/compliance_features.md).
