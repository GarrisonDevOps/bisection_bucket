{{< history >}}

- Les rôles d'administration personnalisés ont été [introduits](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/181346) dans GitLab 17.9 [avec un feature flag](../../administration/feature_flags/_index.md) nommé `custom_admin_roles`. Fonctionnalité désactivée par défaut.
- Les rôles d'administration personnalisés sont [généralement disponibles](https://gitlab.com/groups/gitlab-org/-/epics/15957) dans GitLab 18.3. Le feature flag `custom_admin_roles` est activé par défaut.
- Le feature flag `custom_admin_roles` a été supprimé dans GitLab 19.0.

{{< /history >}}

Vous pouvez créer un [rôle personnalisé](_index.md) en ajoutant une ou plusieurs autorisations personnalisées à un rôle par défaut.

> [!note]
> Certaines autorisations dépendent d'autres autorisations. Par exemple, l'autorisation `admin_vulnerability` nécessite que vous incluiez également l'autorisation `read_vulnerability`. Les dépendances éventuelles sont indiquées dans la colonne `Description` pour chaque autorisation.
