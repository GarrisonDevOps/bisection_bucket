Les clusters Kubernetes [au niveau du projet](../../infrastructure/clusters/connect/_index.md#cluster-levels-deprecated) vous permettent de connecter un cluster Kubernetes à un projet dans GitLab.

Vous pouvez également [connecter plusieurs clusters](multiple_kubernetes_clusters.md) à un seul projet.

## Afficher vos clusters au niveau du projet {#view-your-project-level-clusters}

Pour afficher les clusters Kubernetes au niveau du projet :

1. Dans la barre supérieure, sélectionnez **Rechercher ou accéder à**, puis recherchez votre projet.
1. Dans la barre latérale gauche, sélectionnez **Opération** > **Clusters Kubernetes**.
