title: Organiser le travail avec des projets

Dans GitLab, un projet est un vaste conteneur regroupant tous les aspects de votre travail de développement. Les projets contiennent un dépôt de code, des outils collaboratifs, des fonctionnalités de gestion de projet et des capacités CI/CD. Utilisez votre projet pour organiser toutes les données de votre projet de développement :

- Suivre les tickets
- Planifier le travail
- Collaborer sur le code
- Utiliser les outils CI/CD pour compiler, tester et déployer votre application en continu

Les projets peuvent être disponibles [publiquement, en interne ou en privé](../public_access.md). GitLab ne limite pas le nombre de projets privés que vous pouvez créer.
