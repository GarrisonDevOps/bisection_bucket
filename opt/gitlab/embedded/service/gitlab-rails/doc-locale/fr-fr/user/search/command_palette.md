Vous pouvez utiliser la palette de commandes pour affiner la portée de votre recherche ou pour trouver un objet plus rapidement.

## Ouvrir la palette de commandes {#open-the-command-palette}

Pour ouvrir la palette de commandes :

1. Dans la barre supérieure, sélectionnez **Rechercher ou accéder à** ou utilisez la touche <kbd>/</kbd> pour l'activer.
1. Saisissez l'un des caractères spéciaux :

   - <kbd>></kbd> \- Créer un nouvel objet ou trouver un élément de menu.
   - <kbd>@</kbd> \- Rechercher un utilisateur.
   - <kbd>:</kbd> \- Rechercher un projet.
   - <kbd>~</kbd> \- Rechercher des fichiers de projet dans la branche par défaut du dépôt.
