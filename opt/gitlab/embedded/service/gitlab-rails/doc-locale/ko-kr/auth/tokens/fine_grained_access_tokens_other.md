세분화된 개인 액세스 토큰은 사용자가 부여한 리소스와 권한에만 액세스할 수 있습니다. Git 및 다른 작업에 이를 사용하려면 토큰을 만들고 범위를 정의합니다. 자세한 내용은 [세분화된 개인 액세스 토큰](fine_grained_access_tokens.md)을(를) 참조하세요.

다음 표에서:

- **리소스** 및 **권한**은 토큰을 만들 때 선택할 리소스 및 권한입니다.
- **액세스**는 대상 리소스를 포함해야 하는 경계입니다. 그룹으로 범위가 지정된 토큰은 해당 그룹의 프로젝트에 대한 작업도 승인합니다.

## Git 작업 {#git-operations}

HTTPS를 통한 Git의 암호로 사용되는 세분화된 개인 액세스 토큰은 다음 권한을 보유해야 합니다:

| 작업                          | 리소스 | 권한 | 액세스        |
| ---------------------------------- | -------- | ---------- | ------------- |
| 프로젝트 리포지토리 복제 또는 가져오기 | 코드     | 다운로드   | 프로젝트       |
| 프로젝트 리포지토리에 푸시       | 코드     | 푸시       | 프로젝트       |
| 위키 복제 또는 가져오기               | 위키     | 읽기       | 프로젝트, 그룹[^project-wikis-use] |
| 위키에 푸시                     | 위키     | 만들기     | 프로젝트, 그룹[^project-wikis-use] |
| 스니펫 복제 또는 가져오기            | 스니펫  | 읽기       | 프로젝트, 사용자[^project-snippets-use] |
| 스니펫에 푸시                  | 스니펫  | 업데이트     | 프로젝트, 사용자[^project-snippets-use] |
| Git LFS 객체 다운로드           | 코드     | 다운로드   | 프로젝트       |
| Git LFS 객체 업로드             | 코드     | 푸시       | 프로젝트       |

[^project-wikis-use]: 프로젝트 위키는 프로젝트 경계를 사용하고 그룹 위키는 그룹 경계를 사용합니다.
[^project-snippets-use]: 프로젝트 스니펫은 프로젝트 경계를 사용하고 개인 스니펫은 사용자 경계를 사용합니다.

## 컨테이너 레지스트리 {#container-registry}

[컨테이너 레지스트리](../../user/packages/container_registry/authenticate_with_container_registry.md)에 로그인하는 데 사용되는 세분화된 개인 액세스 토큰은 다음 권한을 보유해야 합니다:

| 작업                                     | 리소스             | 권한 | 액세스  |
| --------------------------------------------- | -------------------- | ---------- | ------- |
| 컨테이너 이미지 가져오기                         | 컨테이너 리포지토리 | 읽기       | 프로젝트 |
| 컨테이너 이미지 및 태그 삭제              | 컨테이너 리포지토리 | 삭제     | 프로젝트 |

> [!note]
> 세분화된 개인 액세스 토큰을 사용하여 컨테이너 이미지를 푸시할 수 없습니다.

## 종속성 프록시 {#dependency-proxy}

[종속성 프록시](../../user/packages/dependency_proxy/_index.md)에 로그인하는 데 사용되는 세분화된 개인 액세스 토큰은 다음 권한을 보유해야 합니다:

| 작업                                     | 리소스         | 권한 | 액세스 |
| --------------------------------------------- | ---------------- | ---------- | ------ |
| 종속성 프록시를 통해 컨테이너 이미지 가져오기 | 종속성 프록시 | 읽기  | 그룹  |

## 아카이브 및 릴리스 자산 다운로드 {#archive-and-release-asset-downloads}

| 작업                                     | 리소스 | 권한 | 액세스  |
| --------------------------------------------- | -------- | ---------- | ------- |
| 리포지토리 아카이브 다운로드                 | 코드     | 다운로드   | 프로젝트 |
| 직접 링크에서 릴리스 자산 다운로드   | 릴리스  | 읽기       | 프로젝트 |

## RSS 및 달력 피드 {#rss-and-calendar-feeds}

RSS 또는 iCalendar 피드 요청을 인증하는 데 사용되는 세분화된 개인 액세스 토큰은 다음 권한을 보유해야 합니다:

| 피드                                          | 리소스              | 권한 | 액세스               |
| --------------------------------------------- | --------------------- | ---------- | -------------------- |
| 사용자 활동                                 | 활동              | 읽기       | 사용자                 |
| 프로젝트 활동                              | 이벤트                 | 읽기       | 프로젝트              |
| 그룹 활동                                | 이벤트                 | 읽기       | 그룹                |
| 프로젝트 커밋                               | 코드                  | 읽기       | 프로젝트              |
| 프로젝트 태그                                  | 코드                  | 읽기       | 프로젝트              |
| 이슈 및 작업 항목(달력 포함)    | 작업 항목             | 읽기       | 프로젝트, 그룹, 사용자 |
| 머지 리퀘스트                                | 머지 리퀘스트         | 읽기       | 프로젝트, 그룹       |
| 내 프로젝트                                 | 프로젝트               | 읽기       | 사용자                 |
| 개인 액세스 토큰 만료 달력     | 개인 액세스 토큰 | 읽기       | 사용자                 |
