이제 GitLab Duo와 MCP 기반 에이전트를 사용하여 머지 리퀘스트 검토 대화를 읽을 수 있습니다. 이를 통해 AI 어시스턴트가 검토자의 피드백, 해결되지 않은 스레드, 그리고 논의 기록의 전체 컨텍스트를 얻을 수 있습니다.

에이전트에 검토 의견을 요약하고, 피드백에 대한 응답을 작성하며, 워크플로우를 떠나지 않고도 머지 리퀘스트 논의에 직접 댓글을 게시하도록 요청할 수 있습니다.
