GitLab Self-Managed를 자체 호스팅 모델과 함께 사용하면 이제 Amazon Bedrock Mantle을 지원하는 공급자로 사용할 수 있습니다. Mantle은 Amazon Bedrock의 OpenAI 호환 추론 엔진이므로 익숙한 OpenAI SDK 및 Bedrock 모델과의 통합을 사용할 수 있습니다. 이 기능은 베타 단계입니다.
