GitLab for VS Code 확장 프로그램의 GitLab Duo 에이전트식 채팅 인터페이스와 JetBrains IDE용 GitLab Duo 플러그인에 새로운 UI가 적용되었으며, 현재 베타로 사용 가능합니다. 새로운 인터페이스는 기존 에이전트식 채팅 패널의 재구축된 버전이며, 동일한 기본 기능을 제공합니다: AI 모델, 에이전트, 슬래시 명령 및 도구 승인.

새로운 UI는 GitLab 19.3에서 다음과 함께 사용할 수 있습니다:

- GitLab for VS Code 6.88.1 이상
- JetBrains IDE용 GitLab Duo 플러그인 3.45.2 이상

새로운 UI를 사용하려면 최상위 그룹 또는 인스턴스에서 [베타 및 실험 기능 활성화](../../../user/gitlab_duo/turn_on_off.md#turn-on-beta-and-experimental-features)를 선택한 후 확장 프로그램을 다시 로드합니다. 언제든지 패널에서 새로운 UI와 기존 UI 간에 전환할 수 있습니다.
