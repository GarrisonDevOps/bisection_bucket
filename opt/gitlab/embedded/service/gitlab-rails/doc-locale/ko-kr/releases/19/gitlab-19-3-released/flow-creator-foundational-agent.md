이제 AI 카탈로그의 목적에 맞게 설계된 기본 에이전트인 Flow Creator를 사용하여 일반 언어 대화를 통해 GitLab Duo Agent Platform용 사용자 지정 플로우를 만들 수 있습니다. Flow Creator를 사용하면 플로우가 수행할 작업을 설명하면 에이전트가 즉시 등록하고 사용할 수 있는 완전하고 실행 가능한 플로우 YAML을 생성합니다. 에이전트는 기존 플로우를 디버깅하고 프레임워크 개념을 설명하는 데도 도움이 될 수 있습니다.
