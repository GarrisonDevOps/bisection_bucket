GitLab 19.3에서 베타로 도입된 VS Code 및 JetBrains IDE의 새롭게 설계된 GitLab Duo 에이전트 대화 UI는 이제 일반 공개되며 기본 레이아웃입니다. 더 이상 베타 및 실험 기능을 켜서 사용할 필요가 없습니다.

새로운 레이아웃에는 탭이 없습니다. 같은 보기에서 대화를 시작하고, 대화 기록을 보고, 에이전트와 모델을 선택합니다.

새로운 레이아웃은 다음에서 기본값입니다:

- GitLab for VS Code 7.2.0 이상
- JetBrains IDE용 GitLab Duo 플러그인 3.50.0 이상

Software Development 플로우를 사용하거나 실행한 플로우를 보려면 패널에서 클래식 레이아웃으로 전환합니다.
