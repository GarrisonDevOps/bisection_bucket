이 릴리스의 인터페이스에 추가된 기타 사항은 다음과 같습니다:

- **승인 필요**를 머지 리퀘스트 설정에서 변경하면 성공 시 토스트 알림이 표시되고 실패 시 경고가 표시됩니다.
- 5개의 컨트롤을 이미 보유한 요구사항이 있는 컴플라이언스 프레임워크는 다시 편집할 수 있습니다.
- 보호 환경 업데이트가 실패하면 API 메시지가 표시됩니다.
- **브랜치 생성** 대화 상자에서 브랜치 이름이 유효성 검사될 때까지 제출 버튼이 비활성화된 상태로 유지됩니다.
- 아카이빙된 레이블은 이슈 및 머지 리퀘스트 목록에 **아카이빙됨** 툴팁을 표시하며, 새로 할당할 수 없습니다.
- 그룹의 SAML 제공자가 비활성화된 동안에는 SCIM 토큰을 생성할 수 없습니다.
- `.4dm` 파일은 구문이 강조 표시됩니다.
- 오른쪽 정렬 Markdown 테이블 열은 고정폭 숫자를 사용합니다.

승인 규칙, 컴플라이언스 프레임워크 및 보호 환경에는 Premium 또는 Ultimate이 필요합니다.
