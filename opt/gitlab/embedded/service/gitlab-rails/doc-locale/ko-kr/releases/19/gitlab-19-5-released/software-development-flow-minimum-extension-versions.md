Software Development 플로우는 이제 GitLab Duo Agent Platform 플로우 레지스트리에서 실행되며, 다른 플로우와 동일한 기반입니다. 플로우는 IDE에서 동일한 방식으로 작동하며, 새로운 수정 사항과 개선 사항은 이 버전으로 제공됩니다.

Software Development 플로우를 계속 사용하려면 편집기 확장을 다음 버전 이상으로 업데이트하세요:

- GitLab for VS Code 6.85.0
- GitLab Duo plugin for JetBrains IDEs 3.40.0
- GitLab for Visual Studio 0.79.0
