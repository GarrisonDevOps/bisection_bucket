GitLab의 이전 버전에서는 큰 Markdown 테이블에서 정보를 찾기 위해 모든 행을 스캔하거나 테이블을 스프레드시트에 복사해야 했습니다.

이제 보기 모드와 미리보기 모두에서 렌더링된 Markdown 테이블을 모든 열 기준으로 정렬할 수 있습니다. 열 헤더에서 정렬 단추를 선택하여 행을 오름차순 또는 내림차순으로 정렬한 후, 초기화를 선택하여 원래 순서를 복원합니다. 키보드로도 정렬할 수 있습니다.
