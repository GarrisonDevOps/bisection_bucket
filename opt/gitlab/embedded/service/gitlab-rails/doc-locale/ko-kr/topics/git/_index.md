Git은 [무료 오픈 소스](https://git-scm.com/about/free-and-open-source) 분산 버전 관리 시스템입니다. 모든 크기의 프로젝트를 빠르고 효율적으로 처리하며 필요할 때 변경 사항을 롤백할 수 있도록 지원합니다.

GitLab은 Git 위에 구축되었으며 소프트웨어 개발을 위한 Git 기반의 완전히 통합된 플랫폼을 제공합니다. GitLab은 Git 위에 많은 강력한 [기능](https://about.gitlab.com/pricing/feature-comparison/)을 추가하여 워크플로우를 개선합니다.
