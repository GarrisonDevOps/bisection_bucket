GitLab은 [많은 타사 서비스와 통합](../user/project/integrations/_index.md)되므로 GitLab에서 직접 이러한 서비스와 함께 작업할 수 있습니다.

| 주제 | 설명 | 초보자에게 적합 |
|-------|-------------|--------------------|
| [Jira 자격증명 생성](../integration/jira/jira_server_configuration.md) | GitLab에서 Jira 이슈 통합을 구성하기 위해 Jira 자격증명을 생성합니다. 예상 시간: 15~20분입니다. | |
| [Jira와 통합](https://about.gitlab.com/blog/gitlab-jira-integration-selfmanaged/) | Jira 이슈 통합을 구성하여 하나 이상의 GitLab 프로젝트를 Jira 인스턴스에 연결합니다. 예상 시간: 30-45분. | |
| [Gitpod과 통합](https://about.gitlab.com/blog/teams-gitpod-integration-gitlab-speed-up-development/)  | Gitpod과 통합하여 모든 GitLab 프로젝트에 대한 개발 환경을 설정합니다. 예상 시간: 30-45분. | |
