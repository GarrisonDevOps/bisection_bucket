## 비개발자로 기여하기 {#contribute-as-a-non-developer}

소프트웨어 개발 사전 지식이 없이 기존 [프로젝트](../user/project/organize_work_with_projects.md)에 참여합니다. 프로젝트 관리, 이슈 추적, 검토 등을 지원합니다.

| 항목                                                                                | 설명                                                | 초보자에게 적합 |
|--------------------------------------------------------------------------------------|------------------------------------------------------------|--------------------|
| [기존 프로젝트에서 이슈 만들기](create_issue_in_existing_project/_index.md) | 프로젝트의 이슈 보드를 사용하여 작업 및 기타 업무를 추적합니다. 예상 소요 시간: 5-10분입니다. | {{< icon name="star" >}} |
| [웹 편집기를 사용하여 파일 편집하기](edit_file_using_web_editor/_index.md)             | 웹 기반 파일 편집기를 사용하여 UI에서 직접 간단한 변경을 수행합니다. 예상 소요 시간: 15-20분입니다. | {{< icon name="star" >}} |
