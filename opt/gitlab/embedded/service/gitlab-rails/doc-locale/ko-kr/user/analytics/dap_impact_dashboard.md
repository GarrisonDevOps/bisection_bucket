GitLab Duo Agent Platform Impact 대시보드는 조직이 Agent Platform을 사용하는 방식과 그 사용량의 비용을 보여줍니다. 대시보드는 그룹과 프로젝트의 집계된 데이터를 사용자 채택 및 참여, 작업 활동, 크레딧 소비에 대한 메트릭으로 표시합니다.

이 대시보드를 사용하여:

- 조직 전체에서 Agent Platform 워크플로의 볼륨을 측정합니다.
- 모델, 플로우 유형, 그룹 또는 프로젝트별로 크레딧 소비를 추적합니다.
- 보관, 이탈, 활동 티어를 포함한 사용자 채택 추세를 모니터링합니다.
- Agent Platform을 가장 적극적으로 사용하는 프로젝트와 그룹을 파악합니다.

## 개요 {#overview}

**개요** 탭은 선택된 범위와 기간에 대한 Agent Platform 사용의 높은 수준의 요약을 표시합니다.

- **활성 프로젝트**: 최소 하나의 Agent Platform 세션이 있는 프로젝트 수입니다.
- **활성 사용자**: 최소 하나의 Agent Platform 세션이 있는 사용자 수입니다.
- **완료된 세션**: 완료된 생성된 Agent Platform 세션의 수입니다.
- **사용된 크레딧**: Agent Platform 세션에서 사용한 크레딧 수입니다.
- **크레딧 사용처**: 각 Agent Platform 플로우 유형별로 사용한 크레딧 수입니다.

## 도입 {#adoption}

**도입** 탭은 선택된 범위와 기간에 대해 사용자가 Agent Platform 기능을 도입하는 방식에 대한 메트릭을 표시합니다.

**사용자** 섹션은 다음 메트릭을 표시합니다:

- **총 사용자**: 최소 하나의 Agent Platform 세션이 있는 사용자 수입니다.
- **신규 vs 재방문**: 최소 하나의 Agent Platform 세션이 있는 신규 및 재방문 사용자의 수와 백분율입니다. 재방문 사용자는 이전 같은 길이의 기간에 Agent Platform 세션이 있던 사용자입니다.
- **활동별 사용자**: Agent Platform 플로우 유형별 사용자 수입니다. 여러 플로우 유형의 사용자는 각 카테고리에서 계산됩니다.

**참여** 섹션은 다음 메트릭을 표시합니다:

- **다중 활동 사용자**: 여러 Agent Platform 플로우 유형에 대한 세션이 있는 사용자 수입니다.
- **포기**: 이전 기간에 하루만 활성이었고 선택된 기간에 돌아오지 않은 사용자 수입니다.
- **티어별 세션 및 상위 기능**: 가장 많이 사용되는 5개의 Agent Platform 기능에 대한 사용자 티어별 세션 수입니다.

**도입 티어** 섹션은 다음 메트릭을 표시합니다:

- **티어 전체 사용자**: 최소 하나의 Agent Platform 세션이 있는 사용자 수입니다.
- **총 세션**: 플로우 유형 및 에이전트 전체 Agent Platform 세션 수입니다.
- **사용자 점유율 vs 세션 점유율**: 사용자 티어별 사용자 및 세션 수입니다.
- **티어별 세션 강도**: 사용자 티어별 사용자 및 세션 수입니다.
- **그룹 및 프로젝트 비교**: 그룹 및 프로젝트별 사용자 수 및 사용된 크레딧입니다.

## 작업 {#work}

**작업** 탭은 선택된 범위와 기간에 대해 Agent Platform 기능이 사용되는 방식에 대한 메트릭을 표시합니다.

**활동 요약** 섹션은 다음 메트릭을 표시합니다:

- **세션**: 총 Agent Platform 세션 수입니다.
- **활동별 세션**: 활동별 Agent Platform 세션 수입니다.
- **시간 경과에 따른 세션**: 플로우 유형별로 스택된 생성된 Agent Platform 세션 수입니다.

**MR 사이클 시간** 섹션은 다음 메트릭을 표시합니다:

- **사이클 시간: Duo 생성**: GitLab Duo에서 생성한 머지 리퀘스트의 열림에서 병합까지의 중앙값 및 75백분위수(일)입니다. 병합된 머지 리퀘스트의 수를 포함합니다.
- **사이클 시간: 기타 모두**: GitLab Duo에서 생성하지 않았으며 인간 작성자가 있는 머지 리퀘스트의 열림에서 병합까지의 중앙값 및 75백분위수(일)입니다. 병합된 머지 리퀘스트의 수를 포함합니다.

머지 리퀘스트는 Agent Platform 세션이 누가 작성자이든 머지 리퀘스트를 열었음을 기록할 때 GitLab Duo에 의해 생성됩니다. 예를 들어 검토하기 위해 세션에서 시작된 머지 리퀘스트는 GitLab Duo에서 생성하지 않은 것으로 계산됩니다.

**기타 모두** 메트릭은 봇, 서비스 계정, 기타 비인간 사용자의 머지 리퀘스트를 제외하므로 GitLab Duo와 사람이 수행한 작업을 비교합니다.

**머지 리퀘스트 볼륨** 섹션은 다음 메트릭을 표시합니다:

- **Duo에서 열음**: GitLab Duo에서 생성한 머지 리퀘스트 수입니다.
- **병합됨: Duo 생성**: GitLab Duo에서 생성한 병합된 머지 리퀘스트 수입니다.
- **병합됨: 기타 모두**: GitLab Duo에서 생성하지 않았으며 인간 작성자가 있는 병합된 머지 리퀘스트 수입니다.
- **Duo에서 생성한 머지 리퀘스트(상태별)**: 선택된 기간에 현재 상태가 있는 GitLab Duo에서 생성한 머지 리퀘스트 수입니다.

**기능 결과** 섹션은 다음 메트릭을 표시합니다:

- **Agent 코드 검토 세션**: 코드 검토 플로우의 세션 수입니다.
- **검토 요청됨**: 코드 검토에 요청된 검토 수입니다.
- **검토 게시됨**: 코드 검토에서 게시한 검토 수입니다.
- **댓글 포함**: 코드 검토에서 최소 하나의 댓글과 함께 게시한 검토 수입니다.
- **댓글 없음**: 코드 검토에서 댓글 없이 게시한 검토 수입니다.
- **Agent 코드 검토 결과(시간 경과)**: 선택된 기간에 코드 검토에 요청되고 게시된 댓글이 있거나 없는 검토 수입니다.
- **Agent 개발자 세션**: Developer 플로우의 세션 수입니다.
- **완료**: Developer 플로우의 완료된 세션 수입니다.
- **일시중단됨**: Developer 플로우의 일시중지된 세션 수입니다.
- **취소됨**: Developer 플로우의 취소된 세션 수입니다.
- **실패함**: Developer 플로우의 실패한 세션 수입니다.
- **Agent 개발자 세션(시간 경과)**: 선택된 기간에 Developer 플로우의 완료, 일시중지, 취소, 실패한 세션 수입니다.
- **Agent Fix Pipeline 세션**: Fix Pipeline 플로우의 세션 수입니다.
- **제안 게시됨**: 실패한 파이프라인에서 GitLab Duo에서 게시한 수정 제안 수입니다.
- **제안 적용됨**: 실패한 파이프라인에서 GitLab Duo에서 게시한 적용된 수정 제안 수입니다.
- **Agent Fix Pipeline 제안(시간 경과)**: 선택된 기간에 실패한 파이프라인에서 GitLab Duo에서 게시하고 적용한 수정 제안 수입니다.
- **Agent SAST 세션**: Agentic SAST 플로우의 세션 수입니다.
- **취약성 발견 후 생성된 MR**: Resolve SAST Vulnerability 세션에서 생성한 머지 리퀘스트 수입니다.
- **Agent SAST 세션(시간 경과)**: 생성된 SAST 플로우 세션 및 세션에서 생성된 머지 리퀘스트 수입니다.

## 지출 {#spend}

**지출** 탭은 선택된 범위와 기간에 대해 Agent Platform 기능이 얼마나 사용되고 있는지에 대한 메트릭을 표시합니다.

- **모델별 크레딧, 기능별**: Agent Platform 기능별로 스택된 다양한 모델에서 사용한 크레딧 수입니다.
- **크레딧**: 사용된 크레딧의 총 수입니다.
- **채팅**: 채팅 세션에서 사용한 크레딧 수입니다.
- **시간 경과에 따른 크레딧**: 기능별로 스택된 시간 경과에 따른 사용된 크레딧 수입니다.

## 대시보드 보기 {#view-the-dashboard}

전제 조건:

- 크레딧 사용 데이터를 보기 위한 그룹의 소유자 역할입니다.

1. 상단 표시줄에서 **검색 또는 이동** > **탐색**을 선택합니다.
1. 왼쪽 사이드바에서 **GitLab Intelligence**를 선택합니다.
1. **DAP Impact**를 선택합니다.
1. 다양한 메트릭을 보기 위해 탭을 선택합니다.
1. 선택사항. 기본적으로 대시보드는 최상위 그룹에 대한 지난 30일 동안의 메트릭을 표시합니다. 결과를 필터링할 수 있습니다:

   - 특정 그룹 또는 프로젝트에 대한 메트릭을 보려면 각 탭에서 **범위** 드롭다운 목록에서 보려는 그룹 또는 프로젝트를 선택합니다.
   - 다른 기간에 대한 메트릭을 보려면 각 탭에서 **기간** 드롭다운 목록에서 보려는 기간을 선택합니다.
   - 선택된 범위와 기간을 초기화하려면 **리셋**를 선택합니다.

1. 표시된 메트릭을 GitLab Duo와 함께 분석하려면 **Duo와 함께 분석**을 선택합니다.
