그룹의 리포지토리 분석은 그룹의 모든 프로젝트에 대한 테스트 커버리지 데이터를 제공합니다.

그룹 리포지토리 분석을 사용하여 다음을 수행할 수 있습니다:

- 그룹의 모든 프로젝트 전반에서 코드 커버리지 추세를 모니터링합니다.
- 커버리지 보고서를 생성하는 총 프로젝트 수 및 작업 수를 추적합니다.
- 분석을 위해 이력 커버리지 데이터를 다운로드합니다.

하위 그룹에 대한 지원은 [이슈 273527](https://gitlab.com/gitlab-org/gitlab/-/issues/273527)에서 제안됩니다.

## 그룹 리포지토리 분석 보기 {#view-group-repository-analytics}

사전 요구 사항:

- 그룹 내의 프로젝트는 테스트 커버리지 데이터를 수집하도록 구성해야 합니다.

그룹의 리포지토리 분석을 보려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **분석** > **리포지토리 분석**을 선택합니다.

## 커버리지 지표 {#coverage-metrics}

그룹 **리포지토리 분석** 페이지에 다음이 표시됩니다:

- **현재 그룹 코드 커버리지**:
  - 커버리지 보고서가 있는 프로젝트의 수입니다.
  - 모든 프로젝트 전반의 평균 커버리지 백분율입니다.
  - 커버리지 보고서를 생성하는 파이프라인 작업의 총 수입니다.
- **평균 테스트 커버리지**: 지난 30일간 그룹의 모든 프로젝트 전반의 평균 테스트 커버리지를 나타내는 그래프입니다.
- **최신 테스트 커버리지 결과**: 그룹의 각 프로젝트에 대한 최신 커버리지 데이터의 목록입니다. 드롭다운 목록에서 프로젝트를 선택하여 결과를 필터링합니다.

## 커버리지 데이터 다운로드 {#download-coverage-data}

그룹의 프로젝트에 대한 이력 커버리지 데이터가 포함된 CSV 파일을 다운로드할 수 있습니다.

CSV 보고서:

- 최대 1000개의 레코드를 포함합니다.
- 각 프로젝트의 기본 브랜치에서의 데이터를 포함합니다.
- 커버리지가 보고된 날당 한 행을 표시합니다.
- 여러 커버리지 보고서가 생성된 경우 해당 날의 마지막 값을 사용합니다.
- 각 커버리지 보고서에 대한 다음 정보를 포함합니다:
  - 커버리지 작업이 실행된 날짜
  - 보고서를 생성한 작업의 이름
  - 프로젝트 이름
  - 커버리지 백분율

커버리지 데이터를 다운로드하려면:

1. 그룹 **리포지토리 분석** 페이지에서 **테스트 커버리지 이력 데이터(.csv) 다운로드**를 선택합니다.
1. 포함할 프로젝트를 선택합니다:
   - **프로젝트** 드롭다운 목록에서 특정 프로젝트를 선택합니다. 프로젝트 드롭다운 목록은 최대 100개의 프로젝트를 표시합니다.
   - 선택 사항. **모두 선택**을 선택하여 그룹의 모든 프로젝트를 포함합니다.
1. **날짜 범위** 드롭다운 목록에서 포함할 시간 범위를 선택합니다.
1. **테스트 커버리지 데이터(.csv) 다운로드**를 선택합니다.
