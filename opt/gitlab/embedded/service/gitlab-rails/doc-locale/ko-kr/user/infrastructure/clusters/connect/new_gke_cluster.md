[`gitlab-terraform-gke` 리포지토리](https://gitlab.com/gitlab-org/ci-cd/deploy-stage/environments-group/examples/gitlab-terraform-gke)의 Google GKE 클러스터 템플릿은 더 이상 GitLab에서 유지 관리하거나 지원하지 않습니다.

코드 기반 인프라(IaC) 솔루션은 [OpenTofu 및 GitLab을 사용한 코드 기반 인프라](../../iac/_index.md)를 참고하세요. 선호하는 도구를 사용하여 자신의 IaC 솔루션을 구현할 수도 있습니다.
