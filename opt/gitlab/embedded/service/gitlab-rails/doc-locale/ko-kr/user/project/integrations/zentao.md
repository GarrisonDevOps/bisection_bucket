[ZenTao](https://www.zentao.net/)는 웹 기반 프로젝트 관리 플랫폼입니다.

지원되는 ZenTao 버전은 다음과 같습니다:

- ZenTao 15.4
- ZenTao Pro 10.2
- ZenTao Biz 5.2
- ZenTao Max 2.2

## ZenTao 구성 {#configure-zentao}

이 통합을 위해서는 ZenTao API 비밀 키가 필요합니다.

ZenTao에서 다음 단계를 완료합니다:

1. **운영자** 페이지로 이동하고 **개발** > **애플리케이션**을 선택합니다.
1. **애플리케이션 추가**를 선택합니다.
1. **이름** 및 **코드** 아래에서 새 비밀 키의 이름과 코드를 입력합니다.
1. **계정** 아래에서 기존 계정 이름을 선택합니다.
1. **저장**을 선택합니다.
