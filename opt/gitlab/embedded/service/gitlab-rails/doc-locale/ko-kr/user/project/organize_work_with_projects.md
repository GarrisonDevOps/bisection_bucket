GitLab에서 프로젝트는 개발 작업의 모든 측면에 대한 광범위한 컨테이너입니다. 프로젝트에는 코드 리포지토리, 협업 도구, 프로젝트 관리 기능 및 CI/CD 기능이 포함되어 있습니다. 프로젝트를 사용하여 개발 프로젝트의 모든 데이터를 구성합니다:

- 이슈 추적
- 작업 계획
- 코드에서 협업
- CI/CD 도구를 사용하여 애플리케이션을 지속적으로 빌드하고, 테스트하고, 배포합니다

프로젝트는 [공개, 내부 또는 비공개](../public_access.md)로 사용할 수 있습니다. GitLab은 만들 수 있는 비공개 프로젝트의 수를 제한하지 않습니다.
