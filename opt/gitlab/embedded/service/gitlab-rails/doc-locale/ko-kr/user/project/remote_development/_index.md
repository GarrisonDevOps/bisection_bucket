원격 개발은 종속성을 설치하거나 리포지토리를 로컬로 복제할 필요 없이 코드 변경을 수행하는 데 사용할 수 있는 기능 세트입니다. 이러한 기능에는 다음이 포함됩니다:

- [Web IDE](#web-ide)
- [작업 영역](#workspaces)

## Web IDE {#web-ide}

[Web IDE](../web_ide/_index.md)를 사용하여 웹 브라우저에서 직접 프로젝트에 변경 사항을 커밋하고 푸시할 수 있습니다. 이렇게 하면 종속성을 설치하거나 리포지토리를 로컬로 복제할 필요 없이 모든 프로젝트를 업데이트할 수 있습니다.

다만 Web IDE는 코드를 컴파일하고 테스트를 실행하거나 실시간 피드백을 생성할 수 있는 네이티브 런타임 환경이 없습니다.

## 작업 영역 {#workspaces}

{{< details >}}

- 티어: Premium, Ultimate

{{< /details >}}

[작업 영역](../../workspace/_index.md)을 사용하여 GitLab에서 직접 완벽한 개발 환경을 생성할 수 있습니다. 이 환경은 원격 서버에서 실행되며 종속성을 설치하거나 리포지토리를 로컬로 복제할 필요 없이 완전한 IDE 경험을 제공합니다.

작업 영역을 사용하면 다음을 수행할 수 있습니다:

- 새로운 개발 환경을 생성합니다.
- 코드 편집기, 터미널 및 빌드 도구를 포함한 완벽한 IDE에 액세스합니다.
- 병합 요청 및 CI/CD 파이프라인을 포함하여 작업 영역을 GitLab의 나머지 부분과 통합합니다.
