명령어 팔레트를 사용하여 검색 범위를 좁히거나 더 빠르게 개체를 찾을 수 있습니다.

## 명령 팔레트 열기 {#open-the-command-palette}

명령 팔레트를 열려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하거나 <kbd>/</kbd> 키를 사용하여 활성화합니다.
1. 다음 특수 문자 중 하나를 입력합니다:

   - <kbd>></kbd> \- 새 객체를 생성하거나 메뉴 항목을 찾습니다.
   - <kbd>@</kbd> \- 사용자를 검색합니다.
   - <kbd>:</kbd> \- 프로젝트를 검색합니다.
   - <kbd>~</kbd> \- 기본 리포지토리 브랜치에서 프로젝트 파일을 검색합니다.
