작업 항목 상태는 **진행중**, **완료**, 또는 **하지 않음**과 같은 작업 항목의 워크플로우에서 특정 단계를 나타냅니다. 상태는 GitLab Free에서 사용되는 기존의 이진 열림/닫힘 상태 시스템보다 더 세밀한 추적을 제공합니다.

<i class="fa-youtube-play" aria-hidden="true"></i> 동영상 개요를 보려면 [Configurable Status for Issues and Tasks - Complete Walkthrough (GitLab 18.2)](https://www.youtube.com/watch?v=oxN95MSo6UU)를 참조하세요.
<!-- Video published on 2025-07-11 -->

상태는 다음을 위해 사용합니다:

- 작업 항목을 완료의 다양한 단계를 거쳐 추적합니다.
- 작업 항목 진행 상황에 대한 더 명확한 가시성을 제공합니다.
- 작업 항목 수명 주기를 관리하기 위해 레이블이 필요한 것을 대체합니다.
- 팀과 프로젝트 전체에서 워크플로우를 표준화합니다.

상태는 작업과 이슈에 사용할 수 있습니다. 에픽 및 다른 작업 항목 유형에 상태를 추가하려는 계획에 대한 정보는 [에픽 5099](https://gitlab.com/groups/gitlab-org/-/epics/5099)를 참조하세요.

## 기본 상태 {#default-statuses}

GitLab은 작업 항목 추적을 시작하는 데 도움이 되는 기본 상태를 제공합니다. 이러한 상태는 수정할 수 없습니다.

기본 상태는 다음과 같습니다:

- **할일**: 작업 항목을 시작할 준비가 된 상태입니다.
- **진행중**: 작업 항목을 활발하게 작업 중인 상태입니다.
- **완료**: 작업 항목이 완료되었습니다.
- **하지 않음**: 작업 항목을 완료하지 않을 것입니다.
- **복제**: 작업 항목이 다른 항목의 복제본입니다.

## 상태 범주 {#status-categories}

상태 범주는 상태가 작업 항목의 상태 및 아이콘에 어떻게 영향을 미치는지를 결정하는 논리적 그룹화입니다. 각 상태는 5개 범주 중 하나에 속합니다:

- **분류**: 새로운 또는 처리되지 않은 작업 항목의 경우입니다.
- **할일**: 시작할 준비가 된 작업 항목의 경우입니다.
- **진행중**: 활발하게 작업 중인 작업 항목의 경우입니다.
- **완료**: 완료된 작업 항목의 경우입니다.
- **취소됨**: 완료되지 않을 작업 항목의 경우입니다.

**완료** 및 **취소됨** 범주의 상태는 자동으로 작업 항목을 닫힌 상태로 설정합니다. 다른 모든 범주는 작업 항목을 열린 상태로 유지합니다.

## 수명 주기 {#lifecycles}

{{< history >}}

- GitLab 18.5에서 `work_item_status_mvc2`라는 [기능 플래그](../../administration/feature_flags/_index.md)로 [도입](https://gitlab.com/gitlab-org/gitlab/-/issues/556113)되었습니다. 기본적으로 활성화됩니다.
- GitLab 18.6에서 [일반 공개](https://gitlab.com/gitlab-org/gitlab/-/issues/576610)되었습니다. 기능 플래그 `work_item_status_mvc2`이 제거되었습니다.

{{< /history >}}

수명 주기는 작업 항목 유형에 적용할 수 있는 상태의 모음입니다. 수명 주기는 상태를 작업 항목 유형 및 네임스페이스 전체에서 일관되게 재사용할 수 있는 의미 있는 워크플로우로 그룹화합니다.

각 수명 주기는 기본 전환 상태를 정의합니다:

- **기본 열린 상태**: 작업 항목을 만들고 다시 열 때 적용됩니다.
- **기본 닫힌 상태**: 작업 항목을 닫을 때 적용됩니다.
- **기본 복제된 상태**: 작업 항목을 복제, 이동 또는 승격으로 표시할 때 적용됩니다.

### 수명 주기 생성 {#create-a-lifecycle}

사전 요구 사항:

- 그룹의 유지 관리자 또는 소유자 역할이 있어야 합니다.
- 이 그룹은 최상위 레벨에 있어야 합니다.

수명 주기를 만들려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **Settings** > **Work items**를 선택합니다.
1. **상태** 섹션에서 **라이프사이클 생성**을 선택합니다.
1. 수명 주기 이름을 추가하고 시작할 기본 수명 주기 구성 또는 기존 수명 주기 중 하나를 선택합니다. 이렇게 하면 새 수명 주기가 상태로 미리 채워지므로 나중에 사용자 지정할 수 있습니다.
1. **생성**를 선택합니다.

### 수명 주기 이름 변경 {#rename-a-lifecycle}

사전 요구 사항:

- 그룹의 유지 관리자 또는 소유자 역할이 있어야 합니다.
- 이 그룹은 최상위 레벨에 있어야 합니다.

수명 주기의 이름을 변경하려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **Settings** > **Work items**를 선택합니다.
1. **상태** 섹션에서 수명 주기 세부 정보 보기에 마우스를 올립니다.
1. **이름 변경**을 선택합니다.
1. 수명 주기의 이름을 변경하고 **저장**을 선택합니다.

### 수명 주기 제거 {#remove-a-lifecycle}

사전 요구 사항:

- 그룹의 유지 관리자 또는 소유자 역할이 있어야 합니다.
- 이 그룹은 최상위 레벨에 있어야 합니다.
- 수명 주기가 사용 중이 아니어야 합니다. 어떤 작업 항목 유형과도 연결되어 있으면 안 됩니다.

수명 주기를 제거하려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **Settings** > **Work items**를 선택합니다.
1. **상태** 섹션에서 제거할 수명 주기에 대해 **라이프사이클 제거**를 선택합니다.
1. 확인 대화 상자에서 **삭제**를 선택합니다.

### 작업 항목 유형의 수명 주기 변경 {#change-lifecycle-for-a-work-item-type}

사전 요구 사항:

- 그룹의 유지 관리자 또는 소유자 역할이 있어야 합니다.
- 이 그룹은 최상위 레벨에 있어야 합니다.

작업 항목 유형의 수명 주기를 변경하려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **Settings** > **Work items**를 선택합니다.
1. **상태** 섹션에서 다음 중 하나를 선택합니다:
   - **라이프사이클 변경**을 선택합니다.
   - 수명 주기가 둘 이상의 작업 항목 유형과 함께 사용되는 경우 드롭다운 목록에서 선택합니다.
1. 작업 항목 유형의 새 수명 주기를 선택합니다. 기존 수명 주기를 선택하거나 새 수명 주기를 만들 수 있습니다.
1. **다음**을 선택합니다.

   모든 현재 상태는 새 수명 주기에서 받을 새 상태를 나타냅니다.

1. 선택 사항. 다른 대체 상태를 선택하려면 드롭다운 목록에서 선택합니다.
1. **저장**을 선택합니다.

## 사용자 지정 상태 {#custom-statuses}

사용자 지정 상태는 해당 네임스페이스의 모든 그룹 및 프로젝트에 대해 기본 상태를 대체하는 네임스페이스 정의 상태입니다. 수명 주기를 편집할 때 사용자 지정 상태는 해당 네임스페이스의 기본 상태를 대체합니다.

사용자 지정 상태에는 다음과 같은 제한이 있습니다:

- 네임스페이스당 최대 70개 상태
- 수명 주기당 최대 30개 상태

### 상태 범주 변경 {#status-category-changes}

상태는 하나의 범주를 가지며, 해당 범주는 상태를 사용하는 모든 수명 주기에 적용됩니다. 다음의 경우 상태의 범주를 변경할 수 없습니다:

- 상태가 다른 수명 주기에서 사용됩니다.
- 상태가 사용 중이고, 새 범주가 상태를 열림 및 닫힘 상태 사이에서 이동합니다. 상태는 작업 항목이 할당되거나 제거된 상태의 대체 상태일 때 사용 중입니다.

다른 범주를 사용하려면 다른 이름과 원하는 범주로 상태를 생성합니다.

### 네임스페이스의 사용자 지정 상태 구성 {#configure-custom-statuses-for-a-namespace}

최상위 그룹에 대해 사용자 지정 상태를 구성하여 해당 그룹, 서브그룹 및 프로젝트의 작업 항목에 사용할 수 있도록 합니다.

사전 요구 사항:

- 그룹의 유지 관리자 또는 소유자 역할이 있어야 합니다.
- 이 그룹은 최상위 레벨에 있어야 합니다.

사용자 지정 상태를 구성하려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **Settings** > **Work items**를 선택합니다.
1. **상태** 섹션에서 작업 항목 유형에 사용되는 수명 주기에 대해 **상태 편집**을 선택합니다.
1. 네임스페이스의 상태를 추가, 편집 또는 순서 변경합니다.
1. **닫기**를 선택합니다.

### 작업 항목의 상태 설정 {#set-status-for-a-work-item}

사전 요구 사항:

- 작업 항목의 프로젝트 또는 그룹의 계획자, 리포터, 개발자, 유지 관리자 또는 소유자 역할이 있거나, 작업 항목의 작성자이거나, 작업 항목에 할당되어야 합니다.

작업 항목의 상태를 설정하려면:

1. 이슈 또는 작업으로 이동합니다.
1. 오른쪽 사이드바에 **상태** 섹션에서 **편집**을 선택합니다.
1. 원하는 상태를 선택합니다.
1. 드롭다운 목록 외부의 아무 영역이나 선택합니다.

작업 항목의 상태가 즉시 업데이트됩니다.
