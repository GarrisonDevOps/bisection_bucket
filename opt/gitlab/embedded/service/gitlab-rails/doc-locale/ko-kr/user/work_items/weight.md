작업 항목이 많으면 전체 개요를 파악하기 어려울 수 있습니다. 가중치가 지정된 작업 항목을 사용하면 특정 작업 항목에 소요되는 시간, 값 또는 복잡성을 더 잘 파악할 수 있습니다. [가중치로 정렬](_index.md#sort-work-items)하여 우선순위를 지정해야 하는 작업 항목을 확인할 수 있습니다.

## 작업 항목 가중치 보기 {#view-the-work-item-weight}

작업 항목 페이지 자체 또는 UI 전체의 여러 관련 보드 및 목록에서 작업 항목의 가중치를 볼 수 있습니다.

개별 작업 항목의 가중치를 보려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트 또는 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **계획** > **작업 항목**을 선택합니다.
1. 작업 항목을 선택합니다.
1. 오른쪽 사이드바의 **가중치** 아래에서 작업 항목 가중치를 봅니다.

**작업 항목** 목록에서 작업 항목 가중치를 보려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트 또는 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **계획** > **작업 항목**을 선택합니다.
1. 필터 상자에서 **가중치** ({{< icon name="weight" >}}) 필터를 선택하고 `1`과 같은 값을 추가합니다.
1. 작업 항목 및 해당 가중치를 봅니다.

이슈 보드에서 작업 항목 가중치를 보려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트 또는 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **계획** > **이슈 보드**를 선택합니다.
1. 개별 작업 항목에서 **가중치** ({{< icon name="weight" >}}) 위에 마우스를 올려놓으면 작업 항목 가중치가 표시됩니다.

**마일스톤** 페이지에서 작업 항목 가중치를 보려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트 또는 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **계획** > **마일스톤**을 선택합니다.
1. 마일스톤을 선택합니다.
1. **마일스톤** 페이지의 오른쪽 사이드바 **총 가중치** 아래에서 작업 항목 가중치의 총합을 봅니다.

## 작업 항목 롤업 가중치 보기 {#view-the-work-item-roll-up-weight}

작업 항목 롤업 가중치는 모든 하위 항목 가중치의 합계가 상위 항목으로 롤업된 값입니다.

예를 들어 작업 항목의 명시적 가중치가 7이고 두 개의 하위 항목의 가중치가 4와 5인 경우 롤업 가중치는 9입니다.

작업 항목의 롤업 가중치를 보려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트 또는 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **계획** > **작업 항목**을 선택합니다.
1. 상위 작업 항목을 선택합니다.
1. **하위 항목** 옆에서 작업 항목 롤업 **가중치** ({{< icon name="weight" >}})를 봅니다.

목록 및 보드에는 작업 항목에 대해 직접 설정된 가중치만 표시됩니다.

## 작업 항목 가중치 설정 {#set-the-work-item-weight}

{{< history >}}

- 작업 항목 가중치를 설정하기 위한 최소 역할이 GitLab 17.7에서 보고자에서 계획자로 [변경](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/169256)되었습니다.

{{< /history >}}

사전 요구 사항:

- 상위 프로젝트 또는 그룹에 대해 계획자, 보고자, 개발자, 유지 관리자 또는 소유자 역할 이상이 필요합니다.

다음이 적용됩니다:

- 작업 항목을 만들거나 편집할 때 작업 항목 가중치를 설정할 수 있습니다.
- 전체 양수를 입력해야 합니다.
- 작업 항목의 가중치를 변경하면 새 값이 이전 값을 덮어씁니다.

### 작업 항목을 만들 때 {#when-you-create-a-work-item}

작업 항목을 만들 때 작업 항목 가중치를 설정하려면 **가중치** 아래에 숫자를 입력합니다.

### 기존 작업 항목에서 {#from-an-existing-work-item}

기존 작업 항목에서 작업 항목 가중치를 설정하려면:

1. 작업 항목으로 이동합니다.
1. 오른쪽 사이드바의 **가중치** 섹션에서 **편집**을 선택합니다.
1. 새 가중치를 입력합니다.
1. 드롭다운 목록 외부의 아무 영역이나 선택합니다.

### 이슈 보드에서 {#from-an-issue-board}

[이슈 보드에서 이슈를 편집](../project/issue_board.md#edit-an-issue)할 때 이슈 가중치를 설정하려면:

1. 이슈 보드로 이동합니다.
1. 이슈 카드(제목 제외)를 선택합니다.
1. 오른쪽 사이드바의 **가중치** 섹션에서 **편집**을 선택합니다.
1. 새 가중치를 입력합니다.
1. 드롭다운 목록 외부의 아무 영역이나 선택합니다.

## 작업 항목 가중치 제거 {#remove-work-item-weight}

{{< history >}}

- 작업 항목 가중치를 제거하기 위한 최소 역할이 GitLab 17.7에서 보고자에서 계획자로 [변경](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/169256)되었습니다.

{{< /history >}}

사전 요구 사항:

- 상위 프로젝트 또는 그룹에 대해 계획자, 보고자, 개발자, 유지 관리자 또는 소유자 역할 이상이 필요합니다.

작업 항목 가중치를 제거하려면 [작업 항목 가중치 설정](#set-the-work-item-weight)할 때와 같은 단계를 따르고 **가중치 제거**를 선택합니다.
