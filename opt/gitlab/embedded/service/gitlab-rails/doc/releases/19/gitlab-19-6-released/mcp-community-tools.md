Community contributors added 10 new capabilities to the GitLab MCP server for 19.6:

- Create a new project. ([Tanvir Singh](https://gitlab.com/tanvir.singh), [MR](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/259294))
- Start a pipeline linked to a merge request. ([Pavan Kumar Sadashiv](https://gitlab.com/hrlpavan), [MR](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/264858))
- Resolve or unresolve a discussion thread. ([Mawueli](https://gitlab.com/mawueli), [MR](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/259502))
- List to-do items. ([Arjun Singh](https://gitlab.com/arjun40779), [MR](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/260099))
- List user events. ([Pavan Kumar Sadashiv](https://gitlab.com/hrlpavan), [MR](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/264864))
- Filter work items by parent. ([Pavan Kumar Sadashiv](https://gitlab.com/hrlpavan), [MR](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/264859))
- Read standalone report artifacts, such as JUnit XML. ([Aditya Parida](https://gitlab.com/adityaswarupparida), [MR](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/262190))
- Read a project's work item types. ([Aditya Parida](https://gitlab.com/adityaswarupparida), [MR](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/267404))
- Read from the end of a job log. ([Deepak Reddy Gathpa](https://gitlab.com/DeepakReddyG), [MR](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/264446))
- Read the rest of a very long line in a repository file after a response cuts it short. ([Deepak Reddy Gathpa](https://gitlab.com/DeepakReddyG), [MR](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/266802))
